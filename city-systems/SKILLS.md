| [`kwatcontrol-ui-config`](kwatcontrol-ui-config/SKILL.md) | Editing KWATControl SQL Server UI, permissions, reports, dropdowns, or navigation metadata | Application business logic or schema creation |
| [`mssql-dynamic-tables`](mssql-dynamic-tables/SKILL.md) | Dynamic file-table schemas, SQUID CRUD generation, or file tracking | Ordinary SQL Server tables unrelated to the dynamic-table pattern |
