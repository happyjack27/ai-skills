# Development Tools Skills

| Skill | Use when | Do not choose for |
|---|---|---|
| [`excel`](excel/SKILL.md) | Excel formulas, VBA, Power Query, or pivot tables | Database SQL or Java spreadsheet integrations |
| [`java`](java/SKILL.md) | Generic Java, JDBC, RMI, servlets, JSP, or legacy modernization | City framework-specific work covered by `kwat-services` or DPW migration |
| [`sql`](sql/SKILL.md) | General SQL queries, schema changes, tuning, or execution-plan review | Domain-specific routing/configuration workflows with their own skill |
| [`webapp-docs`](webapp-docs/SKILL.md) | Documenting an existing web application's schema and use cases | Implementing application code or database migrations |
