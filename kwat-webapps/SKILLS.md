# KWAT Web Application Skills

| Skill | Use when | Do not choose for |
|---|---|---|
| [`kwat-services`](kwat-services/SKILL.md) | Extending the shared `future_package_layout` servlet and REST framework | Generic Java or UI metadata DML |
| [`kwatcontrol-ui-config`](kwatcontrol-ui-config/SKILL.md) | Changing KWATControl metadata for UI rendering, permissions, reports, dropdowns, or navigation | Application business logic or physical schema generation |
| [`mssql-dynamic-tables`](mssql-dynamic-tables/SKILL.md) | Creating standardized SQL Server file tables and generated CRUD procedures | Ordinary SQL tables or general SQL tuning |
