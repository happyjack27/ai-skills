# Upstream Skill Registries

Listed for discovery only. Nothing here is reviewed, copied, or installed. Review each skill's source before adopting it.

| Registry | What it is | Notes and cautions |
|---|---|---|
| [skills.sh](https://www.skills.sh) | Agent Skills Directory with an install-count leaderboard. Skills are listed by source repo (`owner/repo`). | Install counts are popularity, not a security review. Top sources include `microsoft/azure-skills`, `google/agents-cli`, `mattpocock/skills`, `larksuite/cli`, and `runcomfy-agent-skills`. Check the [audits page](https://www.skills.sh/audits) and the source repo first. |
| [skillhub.space](https://skillhub.space) | Registry for OpenClaw skills (1,000+ listed), installed with the `shsc` CLI into `.local/skills`. | Built for OpenClaw, not for this library's frontmatter or routing. Many featured skills involve wallets, trading, or payments, and personal accounts. Treat as untrusted and do not install without a source review. |
