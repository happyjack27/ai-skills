# Shared Skills

| Skill | Use when | Do not choose for |
|---|---|---|
| [`ai-memory`](ai-memory/SKILL.md) | Retrieving persistent knowledge, recording discoveries, checkpointing or resuming work using AI-Memory | Replacing domain-specific procedures, storing secrets, or searching chat history alone |
| [`ssh-servers`](ssh-servers/SKILL.md) | Read-only SSH checks on City web servers (dpwweb1, mpw, webapps, dpwapps) using a dedicated key in ssh-agent | Any server write, restart, or config change; password-based login; local code or database work |
| [`mkesdp-servicedesk`](mkesdp-servicedesk/SKILL.md) | Checking the user's City IT service desk requests at mkesdp.milwaukee.gov (ITDesk, Zoho SDP) in a browser: open or closed status, list views, Microsoft sign-in, and mapping `mkesdp #NNNNN` numbers from TFS items | Creating, editing, assigning, or closing requests; storing requester data or ticket text in memory |
