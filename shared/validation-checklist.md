# Validation Checklist

A universal pre-delivery checklist for AI-generated output.

## Code

- [ ] Code runs without errors on a clean input.
- [ ] Edge cases handled (null, empty, max size).
- [ ] No hardcoded secrets or credentials.
- [ ] Follows naming conventions in `coding-standards.md`.
- [ ] Includes comments where logic is non-obvious.

## Documentation

- [ ] All public interfaces documented.
- [ ] Examples are accurate and tested.
- [ ] No broken links.

## Communication

- [ ] Response directly answers the question asked.
- [ ] No unnecessary filler or padding.
- [ ] Confidence level stated where uncertain.

## General

- [ ] Output matches the requested format.
- [ ] Scope is within what was asked — no unsolicited refactors.
- [ ] Related skills or references cited when relevant.
